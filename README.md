# Dinify — marketing site

Public site `dinify.me`, built with Next.js 16, React 19 and TypeScript.

## Getting started

```bash
npm install
npm run dev                  # http://localhost:3000
npm run build
npm run typecheck
```

- [`CONTEXT.md`](CONTEXT.md) — product, audience, features, pricing, SEO.
